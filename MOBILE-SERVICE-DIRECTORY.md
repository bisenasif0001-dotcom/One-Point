# Step 10 — mobile directory and service details

The mobile directory uses a short title before the existing search. Repeated hero controls and trust cards no longer delay discovery on phones. Category/delivery filters are collapsed behind a Filters control that reports the active selection count. Quick chips scroll horizontally. Category/goal browsing is a separate native disclosure. Existing search, reset and category filtering logic stays in place; search cards retain their original service routes and prices.

At up to 720px, detail pages show the service summary and booking/task action before long process content. The shared generated layout and custom PAN/GST/business layouts are handled separately. PAN actions open the six exact tasks rather than sending a broad PAN request into checkout. GST/business expose task selection; individual service cards retain their exact actions. The MSME detail URL still redirects to the existing business page.

Process, assistance, eligibility and document sections use native disclosures where applicable. Desktop disclosures open and use display:contents to retain the existing component layout. Native sidebar details remain in the DOM for existing service-selection logic. Extra native fixed bars are hidden where the shared fixed action bar already exists.

On phones, the PAN advisory is readable inline rather than a blocking popup. The official-authority disclaimer text is retained. The generated detail template no longer presents its unverified universal refund/tax claims as checkout rules; it points to the selected task and server-confirmed total. Its process description no longer suggests an existing order has already reached verification. Document labels do not guess required/optional status from list position; exact requirements appear for the selected checkout task. Generated upload guidance uses the actual 3 MB limit.

Verification covers 11 widths (320–1440px) for directory, PAN, GST and the MSME/business route, plus additional Aadhaar, passport, income-certificate, voter and printing detail pages at 390px. Checks include early visible search/action, overflow, filters, PAN selection, and disclosure open/close. Existing direct-entry tests cover PAN Back recovery, MSME and printing. Local screenshots block external resources, so remotely loaded icons may be absent. Physical devices/Safari and production release remain for final QA.
