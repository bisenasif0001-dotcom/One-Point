File Checklist

Better files, cleaner output.

Before sending your document, check these small details so prints stay sharp and scans look professional.

Start Request
01

Use PDF for printing

PDF keeps page size, fonts, and layout more stable than screenshots.

02

Keep edges visible

For certificates and IDs, keep all corners visible and avoid cropped photos.

03

Mention color choice

Tell us B&W or color, single or double side, page size, and number of copies.

04

Name files clearly

Use simple file names like Aadhaar-print, passport-photo, or certificate-scan.
